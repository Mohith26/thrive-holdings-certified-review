How the limit is enforced

Methodology

What this adds

The leaderboard reports how much of a return a configuration gets right. The operating question is what it costs to ship a correct return: model spend plus the practitioner time needed to catch what the model got wrong. Reviewing everything is safe but slow; reviewing only what the agent flags is fast but has no guarantee. This view prices each configuration at a guaranteed escaped-error rate.

Review plans

A return is split into the sections a practitioner already reviews one at a time (each W-2, 1099, K-1, Schedule C business, Schedule E property, and so on). Reviewing a section catches its wrong, missing and extra facts, including facts the model never reported. A risk model scores each section from signals available before anyone checks the answer: the share of the section's source pages the draft never cited, disagreement with a second run from GPT-6 Luna at medium reasoning (the page's own cost baseline), whether the agent left an open item, document quality, whether values must be reconciled across files, whether the entity is new this year, the section type and its size. It is a logistic regression trained on last season's field-level review rows, not on these 88 returns.

The guarantee

For a threshold λ, the practitioner reviews every section with risk above λ and accepts the rest as drafted. The loss on return i is the share of its facts that are wrong, missing or extra in accepted sections, with the same denominator as the benchmark's accuracy. It only grows as λ rises. Conformal risk control picks

λ̂ = max { λ : ( Σᵢ Lᵢ(λ) + 1 ) / ( n + 1 ) ≤ α }, n = 88 calibration returns

If benchmark returns and future returns are exchangeable, the expected escaped share on a new return is at most α, whatever the quality of the risk model. A better risk model only buys a cheaper plan. The +1 is the price of a finite calibration set: with 88 returns it costs about 1.1 percentage points of the limit, which is why the strict settings review most sections.

Data in this concept

Accuracy, precision, recall and cost per return are the published values on this page. Fact-level outcomes, section structure, review times and the risk signals are synthetic: a seeded generator creates 88 returns with the published complexity mix (38 simple, 28 medium, 19 complex, 3 ultra-complex) and solves, per configuration, for error thresholds that reproduce its published per-return accuracy, precision and recall to within 0.15 points. The review numbers therefore illustrate the method; they are not measurements of these models.

Limitations

The guarantee is on average over returns, not for every return; a per-return high-probability version (Learn then Test) needs more calibration returns. Exchangeability fails if next season's mix differs, so the calibration set should be refreshed from recent practitioner review rows. Practitioner review is treated as perfect, and every fact counts equally regardless of its dollar impact.
